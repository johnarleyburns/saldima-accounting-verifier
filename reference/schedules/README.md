# reference/schedules

Supporting-schedule reference implementations: depreciation, deferred
revenue, receivables, payables, inventory, debt amortization.

**Status:** Not yet implemented. These land with Phase 3 (fixed assets /
inventory) and Phase 4 (debt) scenarios — see `docs/plan.md` section 18.
Each module will follow the same rules as `reference/accounting/`: pure
Decimal arithmetic, no dependency on Saldima production code, deterministic
output.
